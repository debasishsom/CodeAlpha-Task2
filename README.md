# Task 2 - Unemployment Analysis with Python

## Project Overview

This project analyzes unemployment data in India using Python. The main objective is to understand unemployment trends, regional differences, rural and urban unemployment, and the impact of COVID-19 on unemployment.

## Objectives

- Analyze unemployment rates in India.
- Clean and preprocess the dataset.
- Study unemployment trends over time.
- Compare unemployment across different regions.
- Analyze rural and urban unemployment.
- Examine the impact of COVID-19.
- Generate meaningful visualizations and insights.

## Dataset

The dataset used in this project is:

**Unemployment in India.csv**

The dataset contains information such as:

- Region
- Date
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area (Rural/Urban)

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

- `01_unemployment_analysis.py` - Main Python analysis program
